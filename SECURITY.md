# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems.

If the Security tab offers **Report a vulnerability**, use that private form.
If the form is unavailable, contact the team through [6b6t's community](https://www.6b6t.org/discord) and ask for a private reporting channel.
Do not share exploit details in a public message.

Include steps to reproduce, affected versions, and impact. We respond as soon as we can.

## Scope

- Anything that exposes secrets, tokens, or player data
- Exploits that affect the 6b6t servers or 6b6t.org
- Vulnerabilities in dependencies this project ships
